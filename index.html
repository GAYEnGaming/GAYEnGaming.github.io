INSTALLATION GUIDE

Follow these steps to install your downloaded pack.

01

Download the Pack

Choose a shader or texture pack above and download its ZIP file. Keep the file compressed.

02

Open Minecraft Folder

For Java Edition, press Win + R, enter %appdata%\.minecraft, and open the appropriate folder.

03

Install & Activate

Place the pack in the correct shaderpacks or resourcepacks folder. Open Minecraft and activate it in settings.
