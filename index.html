INSTALLATION GUIDE

Follow these steps to install your pack.

01

Download the Pack

Choose a shader or texture pack and download the ZIP file. Keep it compressed.

02

Open Minecraft Folder

For Java Edition, press Win + R and enter %appdata%\.minecraft.

03

Install & Activate

Put the ZIP in the correct shaderpacks or resourcepacks folder and activate it in Minecraft.
