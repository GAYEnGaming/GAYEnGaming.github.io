📥 Installation Guide

Java Edition

  • Download the ZIP file.
  • Open Minecraft and select Options.
  • For shaders, install a compatible shader loader such as Iris.
  • Open the shader or resource pack folder.
  • Place the downloaded ZIP in the correct folder.
  • Select the pack in Minecraft.

Important

Compatibility depends on the Minecraft version and pack. Do not extract the ZIP unless the pack instructions require it.
